About ReviewGuard AI

An AI-powered system for detecting potentially fake product reviews.

🎯 Project Objective

ReviewGuard AI is designed to analyse product reviews and identify whether a review is potentially fake or likely genuine using Natural Language Processing and Machine Learning.

🔍 How It Works

1. Review Input: User enters a product review.

2. Text Processing: The review is converted into numerical features using TF-IDF.

3. Machine Learning: The trained classification model analyses the review.

4. Prediction: The system predicts whether the review is potentially fake or likely genuine.

5. Confidence: The system displays a confidence percentage for the prediction.

🧠 Machine Learning

ReviewGuard AI uses Natural Language Processing techniques to process review text and a Machine Learning classification model trained using labelled review data.
